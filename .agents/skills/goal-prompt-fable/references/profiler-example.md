# Concise profiler prompt example

Illustrative only; adapt the requirements to the user's actual request.

> Build a profiler that shows where VERA20k simulation tick time goes at the unit
> counts we need to support. Follow ENGINE.md and choose a design that fits the tick
> pipeline. Preserve deterministic state with profiling enabled or disabled; measure
> disabled overhead and demonstrate useful phase timings in representative retail-map
> scenarios. Keep optimization of the measured hotspots outside this task. Give an
> independent critic access to the implementation, evidence and actual output, including
> freedom to challenge whether the measurements represent gameplay. Finish when the
> profiler works through the production path and the stated properties are demonstrated.

This example leaves layout and tools open while supplying a reason and observable
acceptance properties. It supplies no model, effort, budget or publication permission.
Add those only when provided by the real request.
