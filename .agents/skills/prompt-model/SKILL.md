# Prompt Model

For `draft`, produce/adapt the prompt; for `audit`, report consequential improvements.
Use [goal-prompt](../goal-prompt/SKILL.md) for autonomous VERA20k goals.

Keep outcome, essential context, constraints, reference and completion; preserve
explicit scope, authority, model/budget and output requirements. Remove duplicated
rules and choreography that displaces judgment. Retain procedures whose order affects
correctness, meaningful validation and independent critics' access to original evidence.

For model-specific facts, check current capabilities and official provider guidance;
cite source/date and distinguish documentation from local experience. Otherwise write
model-neutral instructions. Avoid performance folklore and guessed effort ladders.
Prompt composition never implies authority to change runtime settings.
