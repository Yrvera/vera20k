# PathfinderClass__EstimateZoneCost — Decode Doc
**Applied Ghidra label:** `PathfinderClass__EstimateZoneCost`

## Summary

`FUN_0042D170` at `0x0042D170` is a `PathfinderClass` helper that computes a cheap
integer route-quality estimate between two map coordinates WITHOUT running cell-level
A*. It is used by blocked-destination fallbacks and target-selection predicates to
gate whether a candidate alternate cell or threat target is "zone-reasonable" before
committing to a full path.

The function:
1. Marks `Pathfinder+0x38 = 1`, resets the pathfinder, clears 3 local zone queues
2. Resolves both endpoints bridge-aware via `MapClass__ResolvePathCoord_BridgeAware`
3. Derives MovementZone from owner type if `param_7 == -1`
4. Calls `Zone_precheck` — on failure returns `0x7FFFFFFF` (hard sentinel)
5. Computes Chebyshev distance between original endpoints
6. Computes zone-chain estimate: `Pathfinder+0xC74 * 2 - 2` + optional bridge-exit adjustments
7. Returns `max(chebyshev, zone_chain_estimate)`

This is NOT a path finder — it produces a small integer for comparison against caller
thresholds (e.g., `<= cheb(original, alternate) + 6` in `FootClass__Find_Path`).
