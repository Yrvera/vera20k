# PathfinderClass__FindNearbyBridgePeer — Decode Doc
**Proposed Ghidra label:** PathfinderClass__FindNearbyBridgePeer

## Summary

`FUN_0042B080` at `0x0042B080` is a 5×5 fallback object-finder called by
`PathfinderClass__UpdateBridgePassability` when the probe cell's object list
(`CellClass+0xE4` or `+0xE8`) is null. It scans the 25 cells in a `dx/dy = -2..+2`
square around the center cell, selects each candidate cell's ground or bridge
object-list based on height proximity, walks the linked list, and returns the first
object that passes a bit-flag gate and a subobject acceptance predicate.

Returns: the first matching `ObjectClass*`, or null (0) if none found.

**Key distinction from the caller's list-selection rule:**
- Caller (`UpdateBridgePassability`): bridge list if probe `>3` height from current
  cell level OR unit's `Foot+0x8C` on-bridge byte is set
- This helper: bridge list if candidate is structural bridge AND `abs(candidate.level - requested_height) >= 3`

The helper does NOT build, cache, or allocate any list — it returns a single pointer.

## Active in YR

**Conditional.** Called by `PathfinderClass__UpdateBridgePassability @ 0x0042ACF0`
only when the probe cell's selected list pointer is null (verified via
`get_function_callers 0x0042B080`). `UpdateBridgePassability` is itself conditional
on `Pathfinder+0x3C != 0` (urgency flag). Active in live YR A* when bridge cells are
in the path and the selected probe list is empty.

### Signature

Not a `__thiscall` — pure free function (no PathfinderClass `this`). The center

### Full algorithm (annotated from decompile)

```c
int FUN_0042b080(short *param_1, int param_2)
{
    short center_x = param_1[0];   // center cell X
    short center_y = param_1[1];   // center cell Y
    int   center_z = DAT_0089C2D8 * param_2;  // height in leptons (leptons/level)

    // 5x5 scan: dy = -2..+2, dx = -2..+2 (outer=dy, inner=dx)
    for (int dy = -2; dy < 3; dy++) {
        for (int dx = -2; dx < 3; dx++) {
            // Compute candidate coordinate
            MapCoord candidate = (center_x + dx, center_y + dy);
            CellClass *cell = MapClass__Get_CellClass(&candidate);

            // Choose object list: ground or bridge
            int obj_list;
            if (!(cell->flags & 0x100)) {
                // Not a structural bridge cell: use ground list
                obj_list = cell->field_0xE4;
            } else {
                int diff = abs((int)(cell->level) - param_2);  // abs(candidate.level - requested_height)
                if (diff < 3) {
                    // Close enough: ground list (threshold: diff 0,1,2 → ground)
                    obj_list = cell->field_0xE4;
                } else {
                    // Far: bridge list (threshold: diff >= 3 → bridge)
                    obj_list = cell->field_0xE8;
                }
            }

            // Walk the object linked list
            for (ObjectClass *obj = obj_list; obj != NULL; obj = obj->field_0x30) {
                // Eligibility gate: bit 2 of object+0x14 (shifted right by 2)
                bool eligible = (obj->field_0x14 >> 2) & 1;
                if (!eligible) continue;

                // Subobject assertion + acceptance predicate
                void *subobj = obj->field_0x674;
                if (subobj == NULL) {
                    GameDebugLog__Assert(0x80004003);
                }
                // Call subobject vtable+0xA0 with center leptons (not candidate leptons)
                bool accepted = (*(subobj->vtable[0xA0]))(
                    subobj,
                    center_x * 256 + 128,   // center cell X in leptons (cell center)
                    center_y * 256 + 128,   // center cell Y in leptons
                    center_z               // height in leptons
                );
                if (accepted) return (int)obj;  // return first accepted object
            }
        }
    }
    return 0;  // no match found
}
```

### Key details

**Height threshold** (verified from decompile):
```c
(int)((uVar6 ^ uVar8) - uVar8) < 3
```
= `abs(candidate.level - requested_height) < 3`. Ground list selected for diff 0, 1, 2; bridge list for diff ≥ 3.
The prior report states `> 2` which is identical to `>= 3`; the decompile uses `< 3` for the ground branch.

**Subobject predicate uses center, not candidate**:
```c
sVar1 * 0x100 + 0x80   // center_x * 256 + 128 (cell center lepton)
sVar2 * 0x100 + 0x80   // center_y * 256 + 128
```
`sVar1` and `sVar2` are loaded from `param_1` BEFORE the candidate loop. The 25 candidate cells
only supply object lists; the acceptance query uses the original center coordinate.

**`DAT_0089C2D8`**: leptons-per-height-level scaling constant (verified as live runtime data
in prior `fn-pathfinder_reset.md` context; `0x0089C2DC` is map width, `0x0089C2D8` is adjacent).

## Control flow summary

```
PathfinderClass__FindNearbyBridgePeer(center_coord, requested_height)
├── center_z = DAT_0089C2D8 * requested_height
├── For dy in [-2 .. +2]:
│   └── For dx in [-2 .. +2]:
│       ├── candidate = (center.x + dx, center.y + dy)
│       ├── cell = MapClass__Get_CellClass(candidate)
│       ├── if !bridge OR abs(cell.level - height) < 3 → list = cell+0xE4 (ground)
│       │   else → list = cell+0xE8 (bridge)
│       └── For each obj in list (via obj+0x30):
│           ├── if !(obj+0x14 >> 2 & 1) → skip
│           ├── if obj+0x674 == NULL → Assert(0x80004003)
│           ├── call (obj+0x674).vtable[+0xA0](subobj, cx*256+128, cy*256+128, center_z)
│           └── if accepted → return obj
└── return NULL
```
