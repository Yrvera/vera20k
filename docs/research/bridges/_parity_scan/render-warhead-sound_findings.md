- Fixture: non-IonCannon warhead, `damage=50`, `BridgeStrength=1500`, hitting a **high body** cell whose overlay is e.g. `0xCE` (in `0xCC<x<0xE7`, the high-direct window) AND whose tile-class is also a high-SM ramp match. gamemd: routes to the FIRST satisfied block in source order — high-SM block at `LAB_00489f77` (it is reached before `LAB_0048a214`), draws ONE `RandomRanged(1,1500)` = say 700; `700 < 50` false → no damage, ONE RNG draw consumed; then falls to `LAB_0048a0a5` low-SM (tile-class won't match a high cell), then `LAB_0048a214` (overlay `0xCE` IS in `0xcc<x<0xe7` → draws a SECOND `RandomRanged`!). If they ever differ by one match (e.g. Rust's HighStateMachine matches a cell gamemd routes only to high-direct), the RNG stream desyncs by ≥1 draw for that event and every subsequent draw this tick — a lockstep break.

- Confidence: LIKELY-DRIFT (the per-path-roll structure is proven different from gamemd's single-route-single-roll; whether it produces a different *draw count* in practice hinges on `path_matches_cell` exactly reproducing gamemd's disjoint routing, which is unproven here — so it cannot be downgraded to PARITY).
