# coord-cell-conversions — gamemd vs Rust Parity Rows

Rows are appended by rust-comparer as compare-* tasks complete. Verdicts: MATCH, DRIFT, MISSING, INTERNAL-ONLY.

**Byte-perfect / pixel-perfect parity doctrine (2026-05-24 update):** DRIFT is the
default for any formula or mechanism difference. INTERNAL-ONLY requires positive
concrete evidence of observable equivalence: algebraic proof, fixture trace, or
empirical bit-identical output. "Probably equivalent in normal play," "edge case,"
"sub-pixel," and "only at map corners" are NEVER sufficient grounds for INTERNAL-ONLY.
Frequency-of-trigger and visibility are for fix priority, not parity verdict.

**Audit pass after doctrine update**: 4 rows previously marked INTERNAL-ONLY have been
re-classified to DRIFT (rows 9, 10, 12, 34) because the original judgments relied on
"not observable at boundaries" / "outside normal play" reasoning that the new doctrine
forbids. Original judgments are noted inline so the reasoning is auditable.
