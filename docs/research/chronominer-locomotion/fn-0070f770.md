## Summary

A rate-timer guard that resets a 3-field auto-fire interval timer in a TechnoClass object.
If the remaining interval is more than 10 frames AND map-editor mode is inactive, it
re-randomizes the timer to a new 4–8 frame interval. Called from
`TeleportLocomotionClass__TimerCheck` after the warp shimmer clears (`TechnoClass+0x271 = 0`),
to re-arm the unit's auto-fire check cycle now that the warp is complete.

Also called from `InfantryClass__DoType_Sequencer` at `0x00520b57` — confirming this is a
general TechnoClass utility, not teleport-specific.

Verified via `decompile_function 0x0070f770` and `get_xrefs_to 0x0070f770`.

## Behavioral analysis

The function implements a **rate-limiter re-arm**: only re-randomizes the timer interval
if more than 10 frames remain on the current interval. This prevents the timer from being
re-rolled too frequently. The check `g_MapEditorMode == 0` suppresses auto-fire timer
activity in the map editor (where units should not fire).

Observable effect in context of teleport locomotion: after `TeleportLocomotionClass__TimerCheck`
clears `TechnoClass+0x271` (the warp-shimmer gate), it calls this function to re-arm the
auto-fire cycle so the unit can resume attacking targets immediately after the warp completes.
Without this call, the unit would not check for attack targets until the existing timer
naturally elapsed.

In `InfantryClass__DoType_Sequencer` context, this serves the same role — rate-limiting the
infantry's action sequencer between animation frames.
