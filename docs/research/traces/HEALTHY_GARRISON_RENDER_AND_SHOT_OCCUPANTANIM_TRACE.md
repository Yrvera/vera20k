# Healthy Garrison Render And Shot OccupantAnim Trace

Date: 2026-05-27
Scope: one healthy occupied static civilian garrison, using stock `CAGAS01` or `CABARN02`, idling and then firing one occupied shot with a weapon that has `OccupantAnim=UCFLASH`.

## Scenario Inputs

- Building examples:
  - `CAGAS01`: `TechLevel=-1`, `Strength=1000`, `CanBeOccupied=yes`, `MaxNumberOccupants=10`, `CanOccupyFire=yes` (`ini/rulesmd.ini:19302..19325`); no active building anim keys, but `MuzzleFlash0..9` (`ini/artmd.ini:8019..8041`).
  - `CABARN02`: `TechLevel=-1`, `Strength=500`, `CanBeOccupied=yes`, `MaxNumberOccupants=5`, `CanOccupyFire=yes` (`ini/rulesmd.ini:21484..21506`); no active building anim keys, but `MuzzleFlash0..4` (`ini/artmd.ini:7056..7067`).
- Weapon example: `UCPara` has `OccupantAnim=UCFLASH` (`ini/rulesmd.ini:22944..22953`).
- `UCFLASH` art has only `Layer=ground` and `Translucent=yes`; no `Rate`, `Start`, `End`, `LoopStart`, `LoopEnd`, `LoopCount`, or `Next` in stock YR (`ini/artmd.ini:16131..16133`).

## Pipeline

Idle body render -> building body SHP frame selection -> optional building anim overlays -> no idle garrison muzzle flash -> occupied shot event -> `OccupantAnim` selection -> fire-port origin -> flash instance spawn -> flash frame advance/deletion -> screen sprite.
