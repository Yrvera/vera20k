# Asset-Parser Retail Byte-Golden Certification — Implementation Plan

> **For Claude:** Execute this plan task-by-task. Each task is self-contained.

**Goal:** Give every parser in `src/assets/` a **named executable certification check**
whose golden source is the retail file bytes themselves (machine-derived, per the
CLAUDE.md certification bar), so parser-parity claims can cite a test instead of prose.

**Architecture:** All new assertions live in a new `#[ignore]`-gated integration-test
target `tests/retail_goldens/` that walks the retail install via the existing
`AssetManager` / `MixArchive` chain. One small shared module (`src/assets/format_sniff.rs`)
is promoted out of `src/bin/audit-assets.rs` so the test and the audit binary share one
format sniffer. No sim/render/app files are touched.

**Design Doc:** none — design approved in chat 2026-07-19 (small scope: test harness +
committed digest fixtures, zero gameplay code). Design context is embedded in the
Grounding Summary below.

---

## Grounding Summary

- **Baseline measured 2026-07-19** via `cargo run --release --bin audit-assets`:
  8,553 sniffed retail files parse with **zero failures** — aud 23, csf 2, fnt 1,
  hva 220, pal 98, shp 2,450, tmp 5,536, vpl 2, vxl 221. 69,034 MIX entries seen,
  5,926 skipped by the sniffer (text/video/PCX/unrecognized). So the parse-total
  certification test can assert zero failures with an **empty allowlist** today.
- **AUD blind spot:** only 23 AUDs are reachable by sniffing MIX entries — the bulk of
  YR audio lives in `audio.bag`/`audio.idx` (parsed by `src/assets/audio_bag.rs`), which
  the sniffer never visits. The suite must walk the bag separately.
- **PCX blind spot:** `detect_format` has no PCX arm; PCX files are in the 5,926 skipped
  entries. A sniff arm gets added.
- **Existing retail-test pattern to mirror:** `tests/tile_coverage.rs:21-36` —
  `RA2_DIR` env var + `#[ignore] // Requires RA2_DIR` + skip-if-missing. Fixtures live
  under `tests/fixtures/<subdir>/` (existing: `bink/`, `rng/`).
- **Digest precedent:** FNV-1a 64 constants already hand-rolled in
  `src/app_radiation_light.rs:20-21`. `std::hash::DefaultHasher` is NOT usable for
  committed goldens (SipHash output is not stable across Rust releases).
- **Certification-bar fit (CLAUDE.md):** "Asset parsers are certifiable today via
  byte-golden comparison against retail files"; Rust-vs-prior-Rust goldens are
  regression ratchets, never parity evidence. The suite therefore separates two tiers by
  test-name prefix: `certify_*` (assertions whose reference is the retail bytes) and
  `ratchet_*` (digests of our own decode output — change detectors only).
- **What still has NO oracle:** decompressor *output values* (SHP RLE-Zero pixels, TMP
  block pixels, AUD ADPCM samples, CSF text). Structural checks + ratchets cover them;
  value-level parity vs gamemd's decoders is **UNVERIFIED-pending-instrument** (Ghidra
  emulation vectors of the native LCW/RLE/ADPCM routines, or pixel goldens — see
  `docs/plans/2026-07-05-parity-convergence-strategy.md` §P2 oracle 1/4).
- **Public repo constraint:** fixtures may contain counts, sizes, ids, filenames, and
  64-bit digests only — never raw retail bytes (palettes, pixels, strings). Digests do
  not reproduce copyrighted content; raw bytes would.
- **Parallel-session safety:** the in-flight substrate refactor touches sim/app/rules
  files; `src/assets/`, `src/bin/`, and `tests/` are untouched in its working set —
  this plan is collision-free.

## Key Technical Decisions

- **Integration-test target `tests/retail_goldens/` (dir with `main.rs`), not unit tests
  in `src/assets/`**: keeps ~700 lines of harness out of parser files; parsers' public
  API is the surface being certified. — **Confidence:** high
  - **Source:** repo pattern `tests/tile_coverage.rs`, `tests/fixtures/`
- **FNV-1a 64 digests, no new crates**: deterministic across platforms/toolchains,
  ~10 lines. Not cryptographic — it is a change detector, which is all a golden needs.
  — **Confidence:** high — **Source:** repo pattern `src/app_radiation_light.rs:19-98`
- **Manifest fixture is generated by the suite itself** (`RETAIL_GOLDENS_WRITE=1`), so
  every number in it is machine-derived from retail bytes — never hand-typed.
  — **Confidence:** high — **Source:** CLAUDE.md "Golden values are machine-derived"
- **Two-tier naming (`certify_*` / `ratchet_*`)**: encodes the CLAUDE.md evidence bar
  in the test names so a future claim can cite the right tier. — **Confidence:** high
  - **Source:** CLAUDE.md "Certification: proof over search"
- **Corpus identity pinned by manifest**: the suite first verifies the install's archive
  set + per-archive entry digests match the manifest; a mismatch reports CORPUS-DRIFT
  (install changed) instead of a fake parser failure. — **Confidence:** high
  - **Source:** inferred (this install has 4 extra disk MIXes + WAE maps; corpus is
    machine-specific)
- **`serde_json` for the manifest**: already a dependency (Cargo.toml `serde_json = "1"`).
  — **Confidence:** high — **Source:** Cargo.toml
- **PAL certify duplicates the two 3-line scale formulas in the test** rather than
  exposing the private fns: an independent restatement pinned to raw file bytes is the
  point of the check. — **Confidence:** high — **Source:** `src/assets/pal_file.rs:180-189`

## Open Questions

### Resolved During Planning

- *Can parse-total assert zero failures?* Yes — measured 8,553/8,553 pass on this
  install (audit-assets run 2026-07-19).
- *Where do most AUDs live?* `audio.bag`/`audio.idx`, not as MIX AUD entries — the bag
  walk is a separate certify test (`src/assets/audio_bag.rs::AudioIndex`).
- *Is `DefaultHasher` acceptable for goldens?* No — SipHash output is not guaranteed
  stable across Rust versions. FNV-1a 64 hand-rolled instead.
- *Can VPL pages be byte-compared?* Yes — `VplFile::pages_slice()` is public
  (`src/assets/vpl_file.rs:86`).

### Deferred to Implementation

- *Do any retail PAL bytes exceed the 6-bit range (>63)?* `certify_pal_roundtrip_bytes`
  asserts ≤63; if a retail palette violates it, that is a real finding about
  `scale_6bit_vga_to_8bit`'s domain (u8-cast truncation for inputs >63) and must be
  investigated, not allowlisted.
- *Do all retail AUDs satisfy `decoded_samples * 2 == header.output_size`?* Unknown until
  the corpus run; a violation is a real parser/format finding to investigate.
- *Exact curated-file list for per-file ratchet digests* — picked at generation time from
  names that resolve via `get_by_name` (Task 8 lists the candidates).

- **Runtime**: full-corpus decode of ~190 MB SHP+TMP is slow in debug. All tests are

- **New invariants may genuinely fail on retail data** (PAL >63 bytes, AUD size

  parser/format, never silently allowlist. That is the suite doing its job.

//! Retail byte-golden certification suite for src/assets/ parsers.
//!
//! Golden source: the retail install's own file bytes (machine-derived, never
//! hand-computed). Two evidence tiers, encoded in test names:
//!
//! - `certify_*` — the assertion's reference is the retail bytes themselves
//!   (parse-total, header-consistency, byte round-trip). These are citable
//!   certification checks under the CLAUDE.md parity bar.
//! - `ratchet_*` — FNV digests of OUR decode output. Regression ratchets only;
//!   explicitly NOT parity evidence (Rust-vs-prior-Rust).
//!
//! Decoder VALUE parity vs gamemd (RLE/LCW pixels, ADPCM samples, CSF text) is
//! UNVERIFIED-pending-instrument: it needs gamemd-derived vectors (Ghidra
//! emulation of the native decompressors) or pixel goldens.
//!
//! Run: cargo test --release --test retail_goldens -- --ignored
//! Regenerate manifest: RETAIL_GOLDENS_WRITE=1 cargo test --release --test retail_goldens -- --ignored certify_corpus_manifest

mod certify_audio;
mod certify_roundtrip;
mod certify_structural;
mod ratchet_digests;

use std::collections::BTreeMap;
use std::path::{Path, PathBuf};

use serde::{Deserialize, Serialize};
use vera20k::assets::asset_manager::AssetManager;
use vera20k::assets::format_sniff::detect_format;

/// FNV-1a 64-bit. Stable across platforms and Rust releases (unlike
/// DefaultHasher/SipHash), which committed goldens require.
pub const FNV_OFFSET: u64 = 0xcbf2_9ce4_8422_2325;
pub const FNV_PRIME: u64 = 0x0000_0100_0000_01b3;

pub fn fnv1a(bytes: &[u8], mut h: u64) -> u64 {
    for &b in bytes {
        h ^= b as u64;
        h = h.wrapping_mul(FNV_PRIME);
    }
    h
}

pub fn fnv1a_start(bytes: &[u8]) -> u64 {
    fnv1a(bytes, FNV_OFFSET)
}

/// Retail install root from RA2_DIR, or None → caller prints SKIP and returns.
/// Mirrors tests/tile_coverage.rs gating so CI (no retail assets) stays green.
pub fn ra2_dir() -> Option<PathBuf> {
    let dir = std::env::var("RA2_DIR").ok()?;
    let p = PathBuf::from(dir);
    p.exists().then_some(p)
}

/// Loads the full archive chain the engine itself loads (core chain + extra
/// disk MIXes), identical to src/bin/audit-assets.rs.
pub fn load_corpus(root: &Path) -> AssetManager {
    let mut am = AssetManager::new(root).expect("AssetManager::new");
    am.load_all_disk_mixes().expect("load_all_disk_mixes");
    am
}

/// One sniffed leaf entry: (archive name, entry id, size, format tag).
pub struct CorpusEntry {
    pub archive: String,
    pub id: i32,
    pub size: usize,
    pub format: &'static str,
}

/// Walk every archive entry, sniff formats, and hand (entry, bytes) to `f`.
/// Iteration order is deterministic: visit_archives order × index order.
pub fn walk_sniffed(am: &AssetManager, mut f: impl FnMut(&CorpusEntry, &[u8])) {
    am.visit_archives(|arch_name, archive| {
        for entry in archive.entries() {
            let Some(data) = archive.get_by_id(entry.id) else {
                continue;
            };
            let Some(fmt) = detect_format(data) else {
                continue;
            };
            let ce = CorpusEntry {
                archive: arch_name.to_string(),
                id: entry.id,
                size: data.len(),
                format: fmt,
            };
            f(&ce, data);
        }
    });
}

/// Committed golden manifest. Counts + 64-bit digests + names only — NEVER raw
/// retail bytes (public repo; digests don't reproduce content, bytes would).
#[derive(Serialize, Deserialize, Default)]
pub struct Manifest {
    pub schema: u32,
    /// archive name -> (entry_count, digest over sorted (id, size) pairs).
    pub archives: BTreeMap<String, (usize, u64)>,
    /// format tag -> sniffed file count.
    pub format_counts: BTreeMap<String, usize>,
    /// format tag -> ratchet rollup digest over all decoded outputs.
    pub decode_rollups: BTreeMap<String, u64>,
    /// Curated per-file ratchet rows: (format, filename, decode digest).
    pub files: Vec<(String, String, u64)>,
}

pub const MANIFEST_PATH: &str = "tests/fixtures/retail_goldens/manifest.json";

pub fn read_manifest() -> Option<Manifest> {
    let text = std::fs::read_to_string(MANIFEST_PATH).ok()?;
    Some(serde_json::from_str(&text).expect("manifest.json parses"))
}

pub fn write_manifest(m: &Manifest) {
    std::fs::create_dir_all("tests/fixtures/retail_goldens").expect("fixture dir");
    let text = serde_json::to_string_pretty(m).expect("serialize manifest");
    std::fs::write(MANIFEST_PATH, text).expect("write manifest");
}

/// True when the run should (re)generate goldens instead of asserting them.
pub fn write_mode() -> bool {
    std::env::var("RETAIL_GOLDENS_WRITE").is_ok_and(|v| v == "1")
}

### Task 3: Corpus manifest + parse-total certification

**Why:** Pins corpus identity (so drift in the install is never misread as parser
failure) and locks the measured 100%-parse baseline as an asserting test.

**Files:**
- Modify: `tests/retail_goldens/certify_structural.rs`

**Step 1: `certify_corpus_manifest`** — builds archive digests from the live install;
in write-mode stores them, otherwise asserts equality:

```rust
use super::*;

#[test]
#[ignore] // Requires RA2_DIR (retail game files)
fn certify_corpus_manifest() {
    let Some(root) = ra2_dir() else {
        println!("SKIP: set RA2_DIR to the retail install");
        return;
    };
    let am = load_corpus(&root);

    let mut archives: BTreeMap<String, (usize, u64)> = BTreeMap::new();
    let mut format_counts: BTreeMap<String, usize> = BTreeMap::new();
    am.visit_archives(|arch_name, archive| {
        let mut h = FNV_OFFSET;
        for e in archive.entries() {
            h = fnv1a(&(e.id as u32).to_le_bytes(), h);
            h = fnv1a(&e.size.to_le_bytes(), h);
        }
        archives.insert(arch_name.to_string(), (archive.entry_count(), h));
    });
    walk_sniffed(&am, |ce, _| {
        *format_counts.entry(ce.format.to_string()).or_default() += 1;
    });

    if write_mode() {
        let mut m = read_manifest().unwrap_or_default();
        m.schema = 1;
        m.archives = archives;
        m.format_counts = format_counts;
        write_manifest(&m);
        println!("manifest written: {MANIFEST_PATH}");
        return;
    }

    let m = read_manifest().expect("manifest.json missing — run once with RETAIL_GOLDENS_WRITE=1");
    assert_eq!(
        m.archives, archives,
        "CORPUS-DRIFT: the install's archive set/index differs from the committed \
         manifest. This is an install change, not a parser failure. If intentional, \
         regenerate with RETAIL_GOLDENS_WRITE=1 (golden re-baseline discipline: one \
         session at a time, note the reason in the commit)."
    );
    assert_eq!(m.format_counts, format_counts, "CORPUS-DRIFT: sniffed format counts changed");
}
```

#[ignore] // Requires RA2_DIR (retail game files)
fn certify_parse_total_zero_failures() {
    let Some(root) = ra2_dir() else {
        println!("SKIP: set RA2_DIR to the retail install");
        return;
    };
    let am = load_corpus(&root);

    walk_sniffed(&am, |ce, data| {

        let outcome: Result<(), String> = match ce.format {
            "shp" => ShpFile::from_bytes(data).map(|_| ()).map_err(|e| e.to_string()),

}

### Task 4: Per-format structural certification (SHP, TMP, VXL, HVA, CSF, FNT, PCX)

**Why:** Parse-Ok proves the parser didn't error; these prove the parsed model is

**Files:**

- `certify_shp_structural` (fields: `src/assets/shp_file.rs:57-84`): re-read the raw

### Task 6: Byte-identity round-trips (PAL, HVA, VPL, MIX names)

**Why:** These are the literal "byte-golden comparison against retail files" — the
parsed model is checked byte-for-byte against the raw retail file, formula included.

**Files:**
- Modify: `tests/retail_goldens/certify_roundtrip.rs`

**Step 1: `certify_pal_roundtrip_bytes`** — for all 98 sniffed palettes:

```rust
// Independent restatement of the two production formulas
// (src/assets/pal_file.rs:180-189) pinned to the raw retail bytes.
fn scale_vga(v: u8) -> u8 { ((v as u16 * 255 + 31) / 63) as u8 }
fn scale_ui(v: u8) -> u8 { v << 2 }
```

Per palette file: assert every raw byte ≤ 63 (6-bit VGA domain — a violation means
`scale_6bit_vga_to_8bit` u8-cast truncates and must be investigated); parse with BOTH
`Palette::from_bytes` and `Palette::from_bytes_gamemd_ui`; for every index `i` and
channel, assert parsed channel equals `scale_vga(raw[i*3+c])` / `scale_ui(raw[i*3+c])`
respectively (alpha excluded — transparency policy is a documented parser choice, not
file data).

**Step 2: `certify_hva_roundtrip_bytes`** — per HVA: assert `section_names[i]` equals
the raw null-padded 16-byte field at `24 + i*16` (trimmed at first NUL), and every
`transforms[f*sections + s]` float bit-equals the raw LE f32s at its file offset
(`f32::to_le_bytes` vs raw slice — bit identity, not epsilon).

**Step 3: `certify_vpl_roundtrip_bytes`** — per VPL: header fields equal raw u32s at
0/4/8; `pages_slice().len() == num_sections as usize`; every page byte-equals the raw
256-byte section at `16 + 768 + page*256`.

engine actually loads — at minimum `rulesmd.ini`, `artmd.ini`, `rules.ini`, `art.ini`,

resolves). For each: locate the archive via `visit_archives` name match and assert

### Task 7: Ratchet decode digests

**Why:** Locks today's decoder OUTPUT (pixels/samples/strings) so any future decoder
change is caught — honestly labeled a ratchet, not parity evidence.

**Files:**
- Modify: `tests/retail_goldens/ratchet_digests.rs`

**Step 1: `ratchet_decode_digests`** — one test; per format accumulate a rollup digest
over the deterministic corpus walk, folding each file's decoded output:

- shp: every frame's `pixels` + the 4 dim/offset u16s (LE) per frame
- tmp: every present tile's `pixels`, `depth`, and LE dims/offsets
- vxl: every limb's voxels as `[x,y,z,color_index,normal_index]` bytes
- hva: every transform's 12 f32 LE byte encodings
- pal: the 256×4 RGBA bytes from `from_bytes`
- csf: every `(key, value)` pair's UTF-8 bytes in `entries()` order, length-prefixed
- aud: the decoded `Vec<i16>` as LE bytes
- fnt/pcx/vpl: decoded RGBA / pages bytes

In write-mode store into `manifest.decode_rollups`; in assert-mode compare, with a
message that names the failing format and states: "decode output changed — if the
change is an intended decoder fix, re-baseline (one session at a time, reason in
commit); ratchet digests are NOT parity evidence."

**Step 2: `ratchet_named_file_digests`** — a curated list of ~10 player-facing assets
resolved by name so failures are legible (candidates — verify each resolves during
implementation, drop any that don't: `gtnkicon.shp`, `cameo.pal`, `unittem.pal`,
`isotem.pal`, `ra2md.csf`, `bus.vxl`, `bus.hva`, plus two TMPs and one AUD chosen from
names in `xcc_database`/`extract-ini.rs`). Digest each decode as above into
`manifest.files`.

**Step 3: Generate** (`RETAIL_GOLDENS_WRITE=1 … ratchet_`), then assert-run → green.

**Step 4: Commit** code + regenerated manifest.
