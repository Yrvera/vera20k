# Brainstorm

Follow [ENGINE.md](../../../ENGINE.md). Establish the affected production path and
state owners, then recommend an approach. Explain alternatives when they represent
a real choice. Cover consequential behavior, integration and retiring old authority,
necessary foundations/migration, validation and unresolved decisions.

For visuals, establish parent draw order, active flags, asset/frame selection,
anchors, clipping and palette. A helper or loaded asset alone does not establish
what appears on screen. For gameplay, follow the surrounding loop and readers.

Use chat for a small design. Save an artifact when requested or needed, normally
`docs/plans/YYYY-MM-DD-<topic>-design.md` in the task's worktree. Design-only work
ends with the design; existing implementation authority includes routine design
choices and continuing execution without another approval gate.
