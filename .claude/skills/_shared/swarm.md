# Parallel investigation

Use up to three independent workers per wave within host capacity; never pad targets.
If delegation is unavailable, work serially and report that limitation.

Assign target, evidence context, leaf skill and return contract. Workers are read-only
unless that workflow/user authority permits reports or corrections with disjoint file
ownership. Never edit Rust, run Cargo, mutate Ghidra, write shared logs or recursively
delegate. Return findings, citations, coverage, unknowns and annotation candidates.

The parent reconciles contradictions and verifies decisive evidence. Report failed or
uninspected targets; partial coverage cannot satisfy an exhaustive request. Integrate
authorized reports/corrections in the task checkout. Ghidra writes require the selected
workflow's authority and [save/readback protocol](../../../docs/research/ghidra-workflow.md),
with all readers stopped. Swarming adds no mutation permission.
